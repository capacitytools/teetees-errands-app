← Firebase Setup 🔥
Step 1

Create a Firebase Account

Go to firebase.google.com and sign in with your Google account. It's completely free!

Step 2

Create a New Project

Click "Create a project" and name it "Teetees Errands". Follow the steps and click "Create".

Step 3

Add Firebase to Your Web App

Click the icon to add Firebase to your web app. Copy the config code below:

// Your Firebase config const firebaseConfig = { apiKey: "YOUR_API_KEY", authDomain: "YOUR_PROJECT.firebaseapp.com", projectId: "YOUR_PROJECT_ID", storageBucket: "YOUR_PROJECT.appspot.com", messagingSenderId: "YOUR_SENDER_ID", appId: "YOUR_APP_ID" };
Step 4

Enable Authentication

Go to "Authentication" → "Sign-in methods" and enable Email/Password. Also enable Google sign-in if you want.

Step 5

Create a Database

Go to "Firestore Database" → "Create Database" → Start in "Test Mode" (for development).

// Database structure collection: users → document: userId → name, email, phone, address collection: orders → document: orderId → service, items, total, status, userId collection: runners → document: runnerId → name, phone, rating, available
